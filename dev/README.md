# ファイル・クエスト 開発用のテストと計算

MOD 本体は `file-quest/mod/`。配る zip に入れたくないので、テストは本体に置かず、ここにまとめる。
どれも `node` だけで動く（追加のインストールは要らない）。MOD のファイルは、実行のたびに一時フォルダへコピーして読む（`stage.mjs`）。

| ファイル | 内容 | 使い方 |
|---|---|---|
| `unit.mjs` | 画面を持たない部品のテスト：素材・装備・売買・セーブの変換、鑑定、敵の数、仲間、酒場の人、冒険者カード、進行度のリセット、依頼、AIの返事の読み取り、冒険の地のたどり方と大きさの検査、候補の集計、放置の年数の計算、勇者の見た目（番号の検査・絵・カード・島の種）、AIの返事の検査、世界の地図（町・遺跡の数と名前）、敵のレベルの決まり方、歩く部品（grid）、ダンジョンの階の作り（どの種からでも同じ形・階段までたどれる・宝箱の中身にファイルが入らない）、部と続きもののセーブ（v3）、町の地図（どの型でも出口・ドア・人のとなりに歩いて着ける・建物は6つ・同じ入力は同じ町）と町の人の話、部の生成（偽のフォルダ14種：章3〜7・全ファイルがちょうど1つの章・全部の章にボス・ぬし・見込みが実際と合う）、物語の設計図（テンプレート・AIの返事の検査と重ね書き・AIに渡す材料）、部の進み方（封印・ボスの階・かけら・結末・保存の検査）、弾よけ（ダメージの計算・あたり・同じ種は同じ弾・どの弾の出かたも 動かないと当たり 自動でよける人なら ほぼ かわせる） | `node file-quest/dev/unit.mjs` |
| `play.mjs` | 画面なしの通しプレイ。ボットが歩き、戦い、酒場でカードの友だちを仲間にし、買い物をして、回収するところまで通す。偽のファイルシステムと、偽のAIを使う | `node file-quest/dev/play.mjs [--noai] [--manual] [--aichaos] [--explore] [--rich] [--reset] [--title] [--gate[=abort]] [--dungeon [--god] [--lv=12]] [--campaign [--keep] [--next]] [--dodge] [--nododge] [--frames=70000] [--debug]`（`--dodge`：敵のこうげきの弾よけを いつも ほんとうによける（ふだんは 3割だけ。あとは Esc でとばす）　`--nododge`：弾よけを オフ（設定）　`--campaign`：部を最後まで通す（無敵・Lv20・長い時間）。章が終わるたびに封印が解け、ぬしを倒し、結末を選び、殿堂に入る。`--keep`：ぬしを守る結末　`--next`：終わったあと次の冒険の地へ）　`--dungeon`：ダンジョン専用。近くの遺跡へ向かい、階を歩いて、宝箱・泉・階段・ボスまで進む（`--lv=12`：最初からそのレベル　`--god`：戦闘中は体力が減らず、ボスまで必ず勝つ。つけないときは、ボスに負けて町に戻る道も通る）　`--gate`：冒険の地の上限を小さくして、大きすぎる場所を選ぶ（`--gate=abort`：調べている途中でやめる道）　`--title`：前回の続きがある状態で起動し、入口から冒険の地を選びなおす（フォルダをたどる・パスを打つ）　`--explore`：何でも触る　`--rich`：お金・素材・絆を持たせ、全役割の仲間をつける　`--reset`：途中で進行度のリセットを3種類呼ぶ） |
| `balance.mjs` | 人数ごとの敵の数の分布どおりに引いて、1戦の強さ（勝率・減るHP・倒れる味方・ターン数）を計算する | `node file-quest/dev/balance.mjs [試行回数] [レベル,レベル…]`（例：`3000 3,8,15,30,50`） |
| `coverage.mjs` | `play.mjs` を モードを変えて何回か動かし、通らなかったコードを ファイルごとに出す（通っていない道に、書き間違いが残っていないかを見る） | `node file-quest/dev/coverage.mjs [フレーム数]`（数分かかる） |
| `sprites.mjs` | ドット絵の見本画像（モンスター・ボス・勇者と仲間の見た目・町の4つの型）を、`file-quest/docs/` に作る（画面を見られないので、目で確かめる） | `node file-quest/dev/sprites.mjs` |

## play.mjs が確かめること
- エラーが 0 であること
- 守るべきファイル（システムの部品・Windows配下・最近のもの・手元の判定で大事そうなもの）が、敵にならず、回収もされないこと
- 通信の宛先が api.anthropic.com だけで、鍵を本文に入れず、secret を指していること
- 複数の敵・4人パーティ・ボス・フレンド・冒険者カード・鍛冶・買取・依頼・回収まで、通ること
- `--aichaos`：AI が失敗・壊れた返事・範囲外の数値・「全部ごみ」を返しても、落ちずに、守るべきファイルが守られること
- `--noai`：キーが無くても、全部が遊べること
- `--manual`：仲間の操作を「自分で選ぶ」にしても、戦闘が進むこと
- 見た目：はじめに名前と すがたを選び、カードメニューで選びなおせる。出したカードのコードに、選んだ見た目が載り、友だちのカードの見た目が そのとおりに、戦闘の味方に出ること。島の種が、選んだ冒険の地から決まること
- 更新日時が1980年（日付なし）のファイルが、来て久しければ敵になり（放置の起点は作成日時）、昨日来たもの・来た日時が分からないものは守られること。画面に出る放置が、10年以上にならないこと
- 通常の起動：冒険の地を選ぶ画面に、ゲームが調べた候補（大きさの目安つき）が出て、先頭を選ぶだけで遊べること。候補は、大きさの検査に通る場所だけ（`--gate` では、大きすぎる Data は出ない）
- `--gate`：大きすぎる冒険の地を選ぶと、AIの鑑定を1回もしないうちに断られ、選びなおして通ること（`=abort`：候補が上限の3倍をこえたところで、調べるのをやめること）
- `--title`：起動の入口で『冒険の地を えらびなおす』を選び、フォルダをたどる・パスを打つ、で選んだ場所がIDつきで入り、そこで遊べること
- 偽のAIは、実機のように「考えるブロック」が先に付く返事を返す。AIへの頼み方が、考える深さ low・上限1000トークン以上であること
- `--reset`：デバッグの進行度リセット2種と、最初からやりなおすと、AIの接続の確認を、実行中に呼んでも、中身が入れかわり（レベル・記録・同行が戻る）、調べた結果や名前などが決まりどおり残り、しばらく遊んでも保存が元に戻らないこと
- 歩ける町：ボットが、町の中を歩いて、必要な店のドアに立って店を開き、人のとなりで向きを変えて話しかけ、出口から出ること（`--dungeon` と `--gate` 以外のモードで確かめる。店は4種類以上、話しかけは1回以上）
- 部と物語：冒険の地を調べると、どのモードでも部と物語ができる（AIが使えれば AI の物語、使えなければテンプレート）。`--campaign` では、全章のボスを倒し、かけらが全部そろい、封印が章の数ー1回解け、物語の仲間が3人加わり、結末と殿堂入りまで通ること。壊れたAIの物語（`--aichaos`）でも、同じ形になること
- 弾よけ：勇者がこうげきされたら 弾よけが出る（`--nododge` では 出ない）。ほんとうによけたとき、自動でよけるボットが ほとんど かわせること（平均1.6発以下・5発以上 当たらない）。Esc でとばせること
- `--dungeon`：遺跡に入って階を下り、宝箱を開け、泉で休み、いちばん奥のボスを倒して外に出ること。`--god` なしでは、ボスに負けて町で目がさめ、ダンジョンの外に出て『いる場所』の記録も消えること。上の2つは、通常のモードでも ボットが遺跡へ行けば通る
- 戦闘と会話の最中の『立ち止まり』を、壁にぶつかったとは数えない。島が作りなおされたら、遺跡の目当ても選びなおす（ボットの作り）

ボットは、メニューの前に同じ画面が続くと Esc で戻る。人間と同じ動き。

## 確かめられないこと
- 画面の見た目・操作の感触・音（`sprites.mjs` の見本画像で、絵だけは見られる）
- 本体（explorer_plus）が出す選択画面・確認画面・コレクションの本当の動き（偽の本体で代用している）
- 実際の Anthropic API の返事

## 数字を変えたいとき
- 敵の強さ・敵の数：`file-quest/mod/encounter.js`（`COUNT_TABLE`・`levelCap`・`enemyStats`・`SCALE_HP`・`SCALE_ATK`）
- ヒーローの強さ：`file-quest/mod/index.js` の `hpMax`・`heroAtk`・`heroDef`
- 変えたら `balance.mjs` で、勝率と減るHPを確かめてから、`unit.mjs` と `play.mjs` を流す
